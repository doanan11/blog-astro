## 参考案例

先看两篇原文，模板是从这两篇里拆出来的：

- [西大光影 · 日升日落，时节如流](https://mp.weixin.qq.com/s/l_2ixdplfpSEHTHB34k_DA)
- [西大印象 · 四季轮转，景致相依](https://mp.weixin.qq.com/s/h_RAcLi0pd0p7Y8CP1Zh6A)

两篇都出自西北大学党委宣传部新媒体中心，风格高度统一：短句成行、一图一段、末段升华、固定落款。

---

## 一、整体结构（五段式）

| 段位 | 作用 | 长度 |
| --- | --- | --- |
| 引子 | 时间或天气 + 对象 + 邀请 | 3 行 |
| 场景铺陈 | 由远及近，写景写光 | 2–3 段 |
| 主体推进 | 景 → 人 → 事，层层深入 | 3–4 段 |
| 情感落点 | 从物抬到人，从人抬到精神 | 1 段 |
| 收尾 | 落款四件套 + 互动引导 | 固定 |

---

## 二、开头三行公式

一行一个信息，三行写完就换行。

**公式 A（风光类）**

```text
{时间或天气}，{一个短促的状态}
{场景}在{光/风/雨}里
{呈现出什么}
```

示例：

```text
日升日落，时节如流
无数西大学子在光影交错间
绘就青春最美的模样
```

**公式 B（活动类）**

```text
{一句时间锚点}
{我们把镜头交给谁}
一起走进{活动名}
```

**公式 C（人物类）**

```text
{一个反差或数字}
{他是谁}
{一句话概括他的选择}
```

**公式 D（成果类）**

```text
{成果本身，带数字}
{背后是多久、多少人}
{这件事意味着什么}
```

## 三、主体写法

### 1. 一句一行，句末不加标点

- 单行不超过 15 字
- 逗号少用，句号几乎不用，靠换行断句
- 一段 3–6 行，对应一张图

### 2. 三种推进逻辑（选一种，不要混用）

- **时间推进**：晨光 → 正午 → 夕阳 → 夜幕
- **空间推进**：校门 → 林荫道 → 教学楼 → 操场 → 天空俯瞰
- **由物及人**：建筑 → 草木 → 光影 → 学子

### 3. 每段必须有一个具体物

不要写"美不胜收""景色宜人"，要写能看见的东西：

> 树叶、窗格、楼梯、光斑、粉笔灰、跑鞋、饭卡、课表

### 4. 段落间用转折词过渡

> 而当夜幕降临之时 / 如果从云端俯瞰 / 雨雾散尽 / 那些曾被我们匆匆略过的

## 四、句式工具箱

### 对仗（每篇收尾用一对足以撑住全文）

- 一树光影藏尽校园岁岁光景 / 一程风雨淬炼少年灼灼初心
- 一半是书声 / 一半是风声
- 走过四季 / 也走过自己

### 排比（主体中段使用）

- 玉兰是挺立的笔锋 / 樱花是春风的笔触
- 那些重复的窗格 / 耸立的教学楼 / 无限延伸的楼梯

### 叠词（每 2–3 段出现一次）

匆匆、悄悄、静静、三三两两、岁岁、年年、轻轻、漫漫

### 拟人动词库（替换"有、是、显得"）

| 平写 | 改写成 |
| --- | --- |
| 阳光照在墙上 | 光吻上墙 |
| 夕阳落在操场 | 余晖为操场编织金色外套 |
| 树叶上有光斑 | 光临摹叶片生命的脉络 |
| 建筑很有秩序 | 线条切割着天空，形成严谨的韵律感 |
| 校园很安静 | 校园在光里一同呼吸 |

### 时间与光意象

晨光、熹光、余晖、暮色、天光、光影、光斑、剪影、金色、斑斓、澄澈

---

## 五、标题公式

- 意象 + 动词 + 场景：**光影里的西大**
- 数字 + 悬念：**这 5 个角落，藏着校园最好的秋天**
- 反差：**从跑三趟到跑一趟**
- 邀请式：**来，和我们一起走完这条路**

忌：深入推进、全面提升、多措并举、扎实开展

---

## 六、收尾四件套

```text
{部门名称}
图/ {摄影}
文&编/ {作者}
责编/ {审核人}
投稿邮箱：xxx@xxx.edu.cn
```

最后一行互动引导，只写一句：

> 为{主体}点亮"小红心"

---

## 七、题材变体

### 人物类

引子用数字或反差 → 一个具体场景切入 → 三件小事 → 一句他自己说的话 → 抬到群体

### 活动类

时间地点前置 → 现场三个画面 → 参与者的一个动作或表情 → 意义一句 → 提醒下次时间

### 成果类

结论先行 → 关键数字 → 最难的一步 → 参与者的名字 → 落到"这项改变对你意味着什么"

### 风光类

完全按第一节五段式，情感落点放在"青春 / 记忆 / 坐标"上

---

## 八、发布前自查（10 条）

1. 开头三行内是否出现具体对象？
2. 有没有超过 20 字的句子？有就拆。
3. 是否一句一行，段落不超过 6 行？
4. 每段是否都有一张对应图片？
5. 有没有出现"高度重视""多措并举"这类套话？
6. 有没有至少一个具体数字或具体物件？
7. 是否用了拟人动词，而非"有/是/显得"？
8. 结尾是否有一对对仗句？
9. 落款四件套是否齐全？
10. 通读一遍，是否有读起来拗口的地方？

## 九、完整示范（风光类短文）

```text
梧桐叶落，秋意渐深
校园在晨雾里
慢慢显出自己的轮廓

让我们走进这一季的校园

晨光穿过枝叶
把影子铺在石板路上
一块一块
像谁遗落的旧信笺

教学楼的窗格
一格一格
把天空切成整齐的方块
风穿堂而过
带走半句没说完的话

午后
跑道泛着白光
有人跑过
影子被拉得很长
又很快收进脚下

暮色合拢时
灯一盏一盏亮起
图书馆的玻璃
把最后一缕余晖
还给天空

那些被我们匆匆略过的角落
其实都写着故事
只是等一个愿意慢下来的人

这里是我们的校园
也是我们共同的青春坐标
```
